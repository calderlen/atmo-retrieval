# Emission diagnostics notebooks

- `current_runs/` preserves the six executed notebooks and their existing outputs exactly as they were.
- `collapse_source/` contains clean, output-free copies for rerunning against each arm's regenerated `collapse_source/` time-series cube.

The collapse-source notebooks also look for the full-emission 1D products under:

`input/hrs/emission/<planet>/<epoch>/<arm>/collapsed/full_emission/`
